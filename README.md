# Relatórios em testes automatizados
Framework: Cypress.io

<p>Após aprendermos como automatizar um fluxo da aplicação é importante definir qual o padrão de projeto que se deve utilizar.
  Aprendendo aqui na EBAC, vamos além de executar testes, vamos gerar relatórios em HTML com duas possível formas:
  - Mochawesome
  - Cypress HTML Report

✋ "Sou iniciante em automação como posso executar os testes?"

✔️ Vem comigo nos passos abaixo:

- Tenha o Git
- Instale o Node.js
- Abra Visual Studio Code (ou outra IDE) e abra uma pasta para o projeto
- Acesse o terminal dentro do VS Code
- Realize um Git Clone desse projeto

Para executar e ver os relatórios com mochawesome:

1 - ```npm run test cy:report``` execute seus testes e visualize automaticamente os relatórios com cypress html reporter em seu navegador padrão
2 - ```npm run test cy:mochaReport``` execute seus testes e visualize automaticamente os relatórios com mochawesome em seu navegador padrão

Bons testes!

</p>
